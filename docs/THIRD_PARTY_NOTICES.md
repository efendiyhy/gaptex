# Pemberitahuan pihak ketiga

- Gaptex menggunakan **Spicetify CLI** sebagai dependensi runtime dan API ekstensi resmi. Source: https://github.com/spicetify/cli — lisensi **LGPL-2.1**. Executable Spicetify tidak disertakan dalam ZIP Gaptex dan diunduh dari installer resmi bila diperlukan.
- Spotify Desktop adalah aplikasi pihak ketiga dari Spotify AB dan tunduk pada ketentuan layanan Spotify.
- Gaptex independen; tidak berafiliasi dengan Spotify AB maupun tim Spicetify.
- Gaptex sendiri: MIT License, lihat `LICENSE`.

Penyebutan sumber dan lisensi ini harus tetap disertakan dalam distribusi publik. Mengganti nama atau menyembunyikan ketergantungan tidak mengubah hak cipta pihak ketiga.
